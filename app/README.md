# Autonomous Shutter Mobile App

Flutter mobile application for voice-based control of autonomous shutter with position checking and remote operation via MQTT.

## Key Features
- Voice-based commanding with speech-to-text
- Real-time shutter position and state monitoring
- MQTT over TLS for secure remote communication
- Intelligent command handling based on current position
- Offline/reconnect handling with visual feedback

See MOBILE_APP_BUILD_PLAN.md for detailed implementation plan.
